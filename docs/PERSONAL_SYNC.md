# 개인 공간 자동 동기화 · 0.38.0

## 집과 회사에서 쓰기

두 PC 모두 본체 0.38.0 이상으로 업데이트하고, 이메일 인증을 마친 같은 메켜놔 계정으로 로그인한다. 로그인 없이 작성한 공간은 계정 공간과 별개이며 자동으로 가져오지 않는다. 기존 0.37.0의 업로드·불러오기 버튼 대신 자동으로 기록을 맞춘다. 설정 → 계정과 개인 자료의 **지금 동기화**로 즉시 확인할 수 있다.

상단의 **동기화됨**은 마지막 확인에 성공했다는 뜻이다. **기기에 저장됨 · 동기화 대기**는 기기 저장을 마쳤으나 전송이 남은 상태이며, **연결 대기**는 오프라인 또는 서버 연결 실패다. **동기화 확인 필요**는 안내를 확인해야 하는 오류다. 연결 확인 전에는 다른 PC에도 저장됐다고 표시하지 않는다. 창을 닫아 트레이에 남아 있더라도 PC 전원이나 네트워크가 끊기기 전에 전송 성공을 확인하는 편이 좋다.

## 저장 범위

홈 배치·데일리 체크·메모·링크·개인 일정만 개인 공간 문서에 보관한다. 일정과 데일리 체크는 같은 할 일 원본을 사용하므로 중복 문서를 만들지 않는다.

메이플 API 키·캐릭터·게임 API 응답·기능 센터 설치 목록·숙제 스케줄러·메이플 달력 등 기능팩 기록·저장 비밀번호·인증 토큰은 이 동기화 대상에 포함하지 않는다. 기능팩 iframe이나 분리 창에 동기화 권한을 추가하지 않는다. 계정은 UID로 분리하고 인증된 소유자만 기존 Firestore Rules를 통과한다.

## 두 PC에 이미 다른 기록이 있을 때

최초 연결은 기기 자료를 클라우드 전체로 교체하지 않고 합친다. 서로 다른 ID의 항목은 함께 남고, 같은 기록의 서로 다른 필드 수정은 가능한 범위에서 합친다. 같은 필드를 양쪽에서 다르게 수정하면 결정적인 ID의 사본에 두 버전을 남겨 반복 동기화 때 사본을 계속 늘리지 않는다. 완료한 날짜와 태그는 집합으로 비교해 기존 항목의 해제도 반영한다.

그다음부터는 기기에 저장된 **마지막으로 확인한 클라우드 사본**을 기준으로 변경·삭제를 판단한다. 한쪽 삭제와 다른 쪽 편집이 겹치면 편집된 기록을 보존한다. 기준 사본이 없는 오래된 PC의 첫 연결은 과거 삭제 의도를 알 수 없으므로 기존 항목을 다시 합칠 수 있다. 삭제 이력을 모든 기기에 영구 보관하는 별도 서버 장부는 이번 버전에 없다.

홈 이름·위젯 설정도 필드별로 합친다. 같은 설정을 동시에 바꾼 경우 서버 값을 적용하고 직전 기기 구성을 복구 사본에 남긴다. 맞춤 설정 중인 미저장 홈 초안은 전송하거나 외부 값으로 교체하지 않는다.

## 기기 사본과 중단 조건

계정의 기기 자료 옆에 동기화 기준과 복구 사본을 저장한다. 첫 병합 전에 기존 기기 자료를 보관하며, 새 충돌이 나면 직전 기기 상태를 복구 사본으로 보관한다. 이는 최근 기기 복구용 사본이며 모든 변경의 무제한 이력은 아니다. 기존 개인 기록과 마찬가지로 별도 암호화하지 않는다. 다른 계정과 게스트의 파일은 접근하지 않는다.

기기 사본을 읽거나 쓰지 못하면 클라우드에 무리하게 덮어쓰지 않는다. 손상된 기준 파일은 자동 초기화하지 않는다. 클라우드 버전이 뒤로 가거나 같은 버전의 내용이 달라져도 자동으로 교체하지 않고 확인을 요청한다. 기기의 최신 원본과 반복 설정을 자르거나 초기화하지 않는다.

## 전송과 충돌 방지

수정 후 약 2초 동안 변경을 모은다. 앱 시작·온라인 복귀·화면 복귀 때 확인하고, 창을 보고 있는 동안 최근 변경이 있으면 약 1분, 한동안 변화가 없으면 약 5분 주기로 확인한다. 숨겨진 창의 반복 읽기는 멈추며 전송이 남은 기기 변경은 보관한다. 네트워크·요청 한도 오류는 재시도 간격을 늘린다. 이 방식은 즉시 실시간 스트림이 아니다.

기존 네이티브 Firestore API의 revision과 조건부 쓰기를 그대로 사용한다. 다른 PC가 먼저 저장했으면 다시 읽어 합치며 한 작업의 경쟁 재시도는 세 번으로 제한한다. 원격 값을 적용하는 중에도 개인 공간의 기존 저장 큐에서 최신 기기 자료와 병합하므로 네트워크 요청을 시작할 당시의 오래된 화면 값으로 교체하지 않는다. 로그아웃·계정 전환·화면 수명이 끝난 요청 결과는 적용하지 않는다.

동기화할 내용이 같으면 서버에 다시 쓰지 않는다. 현재 클라우드 사본은 개인 자료와 홈 구성을 합쳐 800KiB 한도다. 이를 넘으면 원본을 줄여 보내지 않고 기기에 유지하며 안내한다. Firebase 무료 사용량은 무제한이 아니며 요금제·결제 설정은 변경하지 않는다. 서버 연결이 제한돼도 기기 저장은 계속 사용할 수 있다.

## 검증 경계

순수 병합, 두 가상 PC·서버의 경쟁 저장, 재시작·삭제·오프라인 복귀, 실제 개인 저장 큐와 가상 IPC, 기기 메타 파일·계정 분리·발신자 권한을 자동 검사한다. 실제 사용자 자료·로그인 세션을 읽어 시험하지 않는다. 자동 검사와 Windows 패키징은 실제 두 PC의 사용자 로그인이나 Mac 실행 검증을 대신하지 않는다.
