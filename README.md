# 메켜놔

메이플과 일상의 기록을 모으고, 필요한 기능을 선택해 설치하는 데스크톱 개인 대시보드입니다.

**본체 0.38.0 · 메이플 달력 1.2.0 · 숙제 스케줄러 1.0.0 · 생활 계산기 1.0.6 · 생각 보관함 1.0.1**을 독립적으로 관리합니다. 본체는 이메일 회원가입·로그인과 Firebase 개인 공간의 자동 동기화를 지원하며, 로그인 없이도 계속 사용할 수 있습니다. 메이플 달력과 숙제 스케줄러는 별도로 설치합니다. 집과 회사 PC 모두 본체 0.38.0을 먼저 적용한 뒤 기능 센터에서 메이플 달력 1.2.0으로 업데이트하고 숙제 스케줄러 1.0.0을 설치하세요. 두 팩의 최소 본체 버전은 0.35.0이며, 기존 달력 ID·서명 파일 15개·SDK 1·개인 기록 schema 6을 유지합니다.

[0.38.0 Windows 설치 파일](https://github.com/bjpaku-pixel/mekyeonwa-releases/releases/download/v0.38.0/mekyeonwa-0.38.0-windows-setup.exe) · [0.38.0 변경 내역](https://github.com/bjpaku-pixel/mekyeonwa-releases/releases/tag/v0.38.0)

시작 화면은 왼쪽 로그인 없이 시작·자동 실행 ON/OFF, 오른쪽 이메일 로그인·회원가입, 하단 가로 배너 자리로 나눴습니다. 아이디 저장·비밀번호 저장·자동 로그인은 각각 선택합니다. 저장된 비밀번호는 실제 원문 대신 읽기 전용 가림 표시로 보여 주며, 다시 입력을 누르면 직접 입력할 수 있습니다. 로그인한 상태에서 다른 계정으로 로그인을 선택하면 기존 세션을 종료하고 새 로그인 화면을 엽니다. 홈의 상단 배너는 제거했으며 시작 화면의 하단 배너와 기능 사이드바의 배너 자리는 유지합니다. 실제 광고 네트워크는 연결하지 않았습니다. 회원가입 후 인증 메일을 확인하고 인증 상태를 새로고침하면 로그인한 계정의 개인 공간을 자동으로 동기화합니다. Google·네이버 로그인과 홈페이지는 추후 구현합니다.

**집·회사 PC 모두 0.38.0 이상으로 업데이트하고, 이메일 인증을 마친 같은 계정으로 로그인하세요.** 먼저 기기 기록을 읽고 클라우드 기록과 합칩니다. 최초 연결 전 복구 사본을 기기에 보관하며, 서로 다른 항목은 함께 남기고 같은 기록의 경쟁 수정은 결정적인 사본으로 보존합니다. 이후 기기 변경을 모아 자동 전송하고, 창이 보이는 동안 다른 PC의 변경을 주기적으로 확인합니다. 인터넷에 다시 연결하거나 앱으로 돌아와도 확인하며 **설정 → 계정과 개인 자료 → 지금 동기화**로 즉시 요청할 수 있습니다. 단순 최신 PC 전체 덮어쓰기는 하지 않습니다. 로그인 전 자료는 자동으로 가져오지 않습니다. 클라우드 대상은 홈 배치·데일리 체크·메모·링크·개인 일정이며, **메이플 API 키·캐릭터 정보·게임 API 응답·설치 목록·스케줄러와 모든 기능팩 기록은 제외합니다.**

비밀번호는 Firebase 인증으로 검증하며 평문 파일에 저장하지 않습니다. 자동 로그인용 갱신 자격 증명과 선택한 로그인 비밀번호는 각각 별도의 OS 암호화 파일에 보관합니다. 계정 토큰과 저장 비밀번호를 기능팩에 전달하지 않습니다. 클라우드 Rules는 이메일 인증을 마친 본인의 UID 문서만 허용합니다. 개인 기록 파일은 별도 암호화하지 않으며 클라우드도 종단간 암호화는 아닙니다. 정식 공개 전 회원 탈퇴·자료 삭제·개인정보 운영 절차를 갖춰야 합니다. 자동 동기화의 범위·병합·복구·한계는 [0.38.0 동기화 안내](docs/PERSONAL_SYNC.md)를 확인하세요. [0.34.0 계정 구조 그림](docs/guides/account-v34/README.md)은 당시 수동 보관 방식의 기록이며 현재 동작과 구분합니다.

0.25.1은 업데이트 설치 창이 보이지 않던 문제를 수정합니다. 본체가 닫히면 실제 설치 진행 창이 열리고, 추가 옵션이나 마침 클릭 없이 완료 후 앱이 다시 열립니다. 0.25.0이 전달하는 숨김 설치 요청도 새 설치 파일이 진행 창 표시로 전환합니다. 버벅임의 정확한 원인은 아직 확인되지 않았으며 성능 문제가 해결되었다고 단정하지 않습니다.

Windows 설치형 본체 0.25.0부터 작성 중인 내용을 저장하고 상단 **본체 업데이트**에서 **업데이트하고 다시 시작**을 한 번 선택하면 최신 정식 버전 확인 → 다운로드·검증 → 진행 창에서 자동 설치 → 자동 재실행으로 이어집니다. 다운로드 후 설치 버튼을 다시 누르거나 설치 옵션을 다시 고를 필요가 없습니다. 기존 바탕화면 바로가기·자동 실행 선택과 개인 기록을 보존합니다. 자동 확인만으로 다운로드·설치를 시작하지 않습니다. 메이플 달력을 재설치할 필요는 없습니다. Mac 서명·설치·실행·업데이트는 아직 별도 검증이 필요합니다.

**0.24.0 이하에서 처음 0.25.0으로 넘어올 때는 기존 앱의 화면이 유지됩니다.** 이 한 번은 다운로드 뒤 기존 **다시 시작해 설치** 버튼을 눌러야 합니다. 0.25.0 설치 프로그램은 업데이트 경로에서 옵션 확인을 생략하며, 한 번 선택해 끝내는 새 본체 업데이트 화면은 0.25.0을 실행한 뒤부터 적용됩니다.

선택한 도구 이름은 본체 상단에 표시하고, 도구 전환은 우측 기능 사이드바에서 합니다. 생활 계산기 1.0.6과 생각 보관함 1.0.1은 팩 외곽의 틀·패딩·중복 제목을 없애고 본체 중앙 본문에서 스크롤합니다. 두 팩은 본체 0.22.0 이상이 필요합니다.

메이플 달력은 공식 이벤트를 종료일만 또는 전체 기간으로 표시합니다. 기본값은 종료일만입니다. 숙제 스케줄러에서는 캐릭터 설정에서 API 목록 또는 수동 캐릭터를 추가하고 새로고침으로 공식 진행 상태를 조회합니다. 완료 기록은 API가 제공한 상태이며 실시간 게임 감지 기능이 아닙니다. V코어·유니온 챔피언 등의 직접 만든 숙제는 별도의 수동 기록으로 관리합니다. API 키·원본 식별자는 기능팩으로 전달하지 않고 새 숙제 API 결과는 디스크에 저장하지 않습니다. 기존 기록과 과거 배포 파일은 유지합니다.

0.25.0은 한 번 승인해 끝내는 본체 업데이트, 사이드바 접기 애니메이션, 현재 위치 제목의 가독성, 하단 게임 데이터 출처·권리 안내를 보완합니다. 사이드바를 축소하면 메뉴 순서 버튼을 숨깁니다. 홈 오늘의 데일리 체크에서 중복되는 ‘할 일 n · 일정 n’ 요약만 없애며 완료율·남은 할 일과 다른 카드의 개수는 유지합니다. 날짜 미정 안내를 짧게 줄이고 Pretendard 글꼴을 본체·실행 로딩·설치 화면에 맞춥니다. 일부 본체 아이콘에는 원본 Tossface를 적용하고 앱 정보에서 출처·라이선스 전문을 확인할 수 있습니다. 개인 기록 형식·SDK 1·서명·기능팩 파일은 유지하며 기능팩 재설치는 필요하지 않습니다.

설치 안내와 실행 화면을 유지합니다. 임시 베타 안내는 정식 약관이 아니며 내용은 추후 확정합니다. 이메일 계정 기능은 0.34.0부터 제공하며 기존 닫힌 창 정리 오류 수정과 사용자 기록은 유지합니다.

실제 데이터를 읽는 동안만 스켈레톤을 표시합니다. 설정과 개인 기록의 저장 성공을 토스트로 반복 알리지 않으며, 최상단에서 불러오는 중·저장 중·저장됨·저장 확인 필요 상태를 확인합니다. 개인 공간의 저장 버튼은 기기 기록을 저장하고 홈 맞춤 설정 중에는 현재 변경사항을 저장합니다. 인증된 계정의 저장된 개인 기록은 자동 동기화하며 홈 편집 초안은 저장 전까지 전송하지 않습니다. 설치 기능에서는 본체가 처리한 저장 요청의 진행·성공·실패 상태를 표시하며 임의의 기능팩 메시지를 저장 성공으로 간주하지 않습니다. 실패·충돌은 계속 안내합니다. 짧거나 좁은 화면에서는 메모·링크·일정의 기존 추가 버튼이 떠 있는 버튼으로 바뀝니다. 메모와 일정 편집은 하단 시트에서 입력 영역만 스크롤합니다. 새 일정에서 날짜 미정을 고르면 ‘“날짜 미정”으로 저장하면 데일리 체크에서 확인이 가능합니다.’라고 안내합니다.

## 0.38.0 개인 공간 자동 동기화

수정 후 약 2초 동안 변경을 모아 전송합니다. 앱 시작·온라인 복귀·화면 복귀에 확인하며, 화면을 보고 있을 때 최근 활동 중에는 약 1분, 오래 변화가 없으면 약 5분 주기로 확인합니다. 숨겨진 창의 반복 확인은 멈추고, 전송 대기 중인 기기 변경은 보관합니다. 연결 실패와 무료 한도 오류에는 간격을 늘려 재시도합니다. 즉시 실시간 연결이나 무료 사용량을 무제한 보장하는 방식은 아닙니다. 클라우드의 현재 사본은 합산 800KiB 한도이며 변경 이력 서비스는 아닙니다. 기기 동기화 기준·복구 사본도 개인 기록과 마찬가지로 별도 암호화하지 않습니다.

## 0.37.0 화면과 창 설정

설정 → 해상도와 창 크기에서 1280 × 720, 1366 × 768, 1600 × 900(새 기기 기본), 1680 × 1050, 1920 × 1080, 전체 화면을 선택합니다. 즐겨찾기 한 개가 상단 해상도 버튼과 다음 실행 크기에 함께 적용됩니다. 현재 창만 임시로 조절해도 즐겨찾기를 덮어쓰지 않습니다. 기존 기기의 명시적인 즐겨찾기는 유지하고, 이전 1680 × 945 선택은 1680 × 1050으로, 이전 1366 × 768 전체 화면 선택은 현재 전체 화면으로 읽습니다. 다음 실행 크기를 별도로 고르는 목록은 제거했습니다. Alt+Enter 전체 화면 전환은 ON/OFF할 수 있으며 OFF일 때는 해당 키 입력을 가로채지 않습니다. 창 설정은 이 기기에만 보관하고 OS 모니터 해상도를 변경하지 않습니다.

기능 센터의 메이플 분류는 첫 줄에 모든 분류·편리 기능·이벤트·캐시·직업, 둘째 줄에 내실 분석기·강화 도구·템셋팅·보스·준비 중을 표시합니다. 숙제 스케줄러는 편리 기능의 하위 분류에서 설치합니다. 기능 업데이트 확인에 성공하면 모든 영역에서 업데이트할 수 있는 팩을 모아 첫 항목을 선택합니다. 실제 업데이트는 사용자가 승인해야 시작합니다. 필터 초기화와 기능 사이드바의 중복 기능 요약 박스는 제거했으며, 각 도구의 별도 창 버튼은 유지합니다.

메모와 링크는 상단 모아 보기와 하단 태그·분류 영역을 구분하며, 메모에 **+ 태그 만들기·관리**를 제공합니다. 빈 태그 목록은 계정별로 이 PC에 보관하고, 실제 메모에 연결한 태그는 메모와 함께 백업합니다. 링크 순서는 첫 줄 왼쪽 1번·오른쪽 2번, 다음 줄 왼쪽 3번·오른쪽 4번입니다.

놓친 일은 최신 날짜부터 표시합니다. 날짜 미정 비우기는 완료한 항목만 비우기와 전체 비우기 중에서 선택한 뒤 다시 확인해야 삭제합니다. 삭제 대상 확인 이후에 추가하거나 날짜를 지정한 항목, 완료를 해제한 항목은 보존합니다. 달력은 완료 체크 ON/OFF 선택을 기기·계정별로 저장하고, 항목 오른쪽 버튼으로 완료하거나 해제합니다. 이날만은 흰색, 주 1회는 노란색, 매일 반복은 빨간색 배경을 유지하며 완료는 초록색 글씨와 체크로 구분합니다. 기본 날짜 칸 높이는 줄이되 항목이 많아지면 함께 늘어납니다.

## 0.36.0 한국어 인증과 선택 비밀번호 저장

인증·비밀번호 재설정 메일 요청은 `X-Firebase-Locale: ko`를 사용합니다. Firebase 기본 템플릿 언어도 한국어로 저장하고, 콘솔에서 인증·비밀번호 재설정 메일의 제목과 본문을 확인했습니다. 사용자 지정 발신명·제목 저장은 Firebase가 `EMAIL_TEMPLATE_UPDATE_NOT_ALLOWED` 오류로 거부하여 적용하지 못했습니다. 현재는 Firebase 기본 한국어 서식을 사용하며, 실제 수신 메일과 링크 처리 화면은 별도 확인이 필요합니다.

이메일 인증은 무료 기본 구조를 유지합니다. 전송에 성공하면 5분 동안 이메일 확인 안내를 표시하고, 메일이 도착하지 않았을 때 재전송할 수 있습니다. 5분은 확인 안내 시간이며 Firebase 인증 링크의 실제 만료 시간을 변경한 것은 아닙니다. 재전송은 기존의 60초 요청 제한을 따릅니다. 이메일 인증 전 클라우드 접근을 차단하는 보안 규칙도 유지합니다.

비밀번호 저장은 자동 로그인과 별도로 선택합니다. 저장을 켜고 로그인에 성공했을 때만 OS의 `safeStorage`로 암호화한 로그인 정보를 PC의 `secrets/firebase-login.bin`에 보관합니다. 다음 실행에서는 이메일과 저장 여부만 화면에 전달하고, 비밀번호는 본체 네이티브에서 복호화하여 Firebase 로그인 요청에만 사용합니다. 비밀번호 원문을 읽는 IPC는 제공하지 않으며 브라우저 저장소·기능팩·클라우드 백업에 비밀번호를 전달하지 않습니다. OS 암호화를 사용할 수 없을 때 평문으로 대신 저장하지도 않습니다.

저장을 해제하면 저장 파일을 지웁니다. 로그아웃은 자동 로그인 토큰을 지우지만, 사용자가 별도로 선택한 비밀번호 저장은 유지합니다. 공유 PC에서는 저장을 끄고 사용하세요. OS 암호화가 같은 Windows 계정에서 실행되는 악성코드나 이미 장악된 PC까지 보호한다고 보장하지는 않습니다. [Electron safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)와 [Firebase 메일 언어](https://firebase.google.com/docs/reference/rest/auth#section-send-email-verification)를 참고하세요.

메이플 API 응답·기능 센터 설치 목록·기능팩 기록·넥슨 API 키는 Firebase 백업에 포함하지 않습니다. 게임 클라이언트와 OS 모니터 해상도에 개입하지 않으며, 기존 SDK 1·개인 기록 schema 6·서명된 기능팩 파일 15개를 유지합니다.

## 개인 공간

- **홈 맞춤 설정**을 누르면 홈에서 바로 편집합니다. 카드 손잡이를 마우스로 끌거나 위·아래 버튼으로 순서를 바꾸고, 제목·표시·너비를 정한 뒤 강조된 하단 막대에서 저장합니다. 이동 안내는 ! 도움말로 확인합니다. 취소와 기본 구성 복원을 제공하며 숨긴 카드의 기록은 유지합니다. 너비는 절반·전체로 고르며 고정 메모는 각각 4개·10개를 보여 줍니다. 즐겨찾기 링크 아이콘은 주변 테두리를 없앴습니다.
- **데일리 체크와 일정은 같은 할 일 원본**을 사용합니다. 어느 화면에서 추가해도 날짜·중요 표시·시간·메모·반복·완료가 함께 반영됩니다. 일정은 달력으로 보고 데일리에서 자세히 체크합니다. 기존 버전에서 작성한 별도 일정도 보존·표시·편집합니다.
- 매일 반복은 날짜별로, 매주 목표는 선택한 초기화 요일부터 다음 주 전날까지 한 번 완료합니다. 미래 회차를 복사해 저장하지 않고 필요한 날짜에 계산합니다. 매일·주 1회에 선택 종료일을 지정하면 그날까지 포함해 표시합니다. 지정하지 않으면 계속 반복합니다. 종료일 없는 반복과 완료 이력의 저장 한도는 별개입니다.
- 달력의 날짜 칸을 누르면 간결한 빠른 등록 창에서 Enter로 연속 등록하며 모든 항목을 표시합니다. 항목의 아이콘·즐겨찾기는 맨 오른쪽에 두고 이날만은 기본 흰색, 매일 반복은 빨강, 주 1회는 노랑으로 구분합니다. 다크 테마에서는 읽을 수 있는 해당 테마 배경을 사용합니다. 반복 기록 전체 삭제는 완료 내역도 지워진다는 확인을 받습니다. 제거 모드에서도 달력을 유지하고 휴지통으로 선택합니다. 일정 초기화는 모든 달의 날짜 있는 기록을 확인 후 삭제하며 날짜 미정·메모·링크는 남깁니다. 옆의 지나간 일정 초기화는 오늘 이전의 이날만 항목만 개수를 확인한 뒤 삭제합니다. 반복 규칙과 그 완료 기록, 오늘·미래·날짜 미정 항목은 제외하며 확인 후 날짜가 바뀌거나 새로 추가한 항목도 삭제하지 않습니다. 이날만 항목은 마우스로 끌어 다른 날짜로 옮기고 반복 일정은 상세 편집을 사용합니다. 일정 이동은 포인터 좌표로 판정합니다. 다른 달은 이전/다음 달 버튼에650ms 머문 뒤 원하는 날짜에 놓습니다. 취소/저장 실패 시 원래 날짜를 유지합니다.
- 메모는 내용과 태그를 구분해 입력하고 저장합니다. 새 메모의 기본 색상은 화면 테마를 따르며 흰색·회색·검은색과 기존 색상을 직접 고를 수 있습니다. 새 메모는1,000자까지 작성합니다. 기존 긴 메모는 원문을 보존합니다. 태그·색상 설정은 새 메모를 만들 때 펼치고 기존 메모를 열 때 접습니다. 목록 카드는 왼쪽 약 80%에 본문·태그·수정일을, 구분선 오른쪽 약 20%에 선택·고정·삭제·위아래 순서 도구를 배치합니다. 본문은 화면에서 네 줄까지 표시하지만 저장 원문을 자르지 않습니다. 별도 이동 버튼과 이동창은 제거했으며 카드 드래그·태그 담기와 직접 순서 버튼은 유지합니다. 상단 고정·모든 메모·태그 없음의 보기 순서를 설정합니다. 내 태그 관리에서 드래그/화살표로 순서를 저장하고 선택한 태그를 확인 후 해제합니다. 메모 내용은 유지합니다.
- 링크는 즐겨찾기·전체·미분류의 보기 순서를 정하고, 포인터로 순서·분류를 바꿉니다. 직접 아이콘과 네이버·메이플 파비콘을 지원하며 기본 웹브라우저로 엽니다.

개인 데이터 schema 6은 이전 1~5 기록을 읽습니다. 최초 새 형식 저장 전 이전 원본을 pre-v6 백업으로 한 번 보관합니다. 기록이 저장된 상태에서 구버전으로 되돌리면 새 형식을 읽지 못할 수 있습니다. 현재 기기 기록·완료 내역에는 1MiB와 항목별 한도가 있습니다. Firebase를 통한 개인 기록의 수동 업로드·불러오기는 제공하며, 파일로 내보내기·가져오기와 실시간 기기 간 자동 동기화는 추후 작업입니다.

홈 중요 일정은 날짜가 지나거나 완료되어도 별을 해제할 때까지 남습니다. 카드 오른쪽 별은 중요 표시만 해제하고 일정·완료 기록은 유지합니다. 데일리 완료 항목은 취소선 대신 초록색으로 표시합니다.

홈의 **중요 메이플 기능**과 **중요 개인 기능**은 각각 이동·숨김·너비를 정하는 독립 카드입니다. 이전에 한 카드로 저장한 구성은 두 카드로 변환하며 제목·위치·표시·너비 선택을 보존합니다. 즐겨찾기 링크는 왼쪽부터 오른쪽으로 채우고, 절반·전체 카드의 실제 폭에 들어가는 두 줄만 표시합니다. 나머지 링크 기록은 유지하며 링크 화면에서 확인할 수 있습니다. 날짜 미정 할 일은 홈에서 제외하지만 데일리 체크에는 남깁니다.

## 기능 센터

메이플 기능·개인 기능·준비 중·준비 중, 네 영역을 표시하며 검색은 그 위에 배치합니다. 검색어를 입력하면 선택 영역·분류와 관계없이 모든 영역을 검색하고 결과의 소속을 표시합니다. 지우면 이전 필터로 돌아갑니다. 분류는 모든 분류를 포함한10칸으로 계속 표시하고 빈칸은 준비중으로 둡니다. 분류 선택은 아래 결과만 바꾸고 하위 분류는 별도로 표시합니다. 사용 가능한 영역은 목록이 제공하는 상하위 분류로 탐색합니다. 이벤트·보스·강화 도구 안에 여러 하위 분류를 추가할 수 있으며 분류를 바꿔도 같은 팩 ID와 기록을 사용합니다. 준비 중인 영역은 아직 선택·설치할 수 없습니다. 새로 추가된 기능은 이름 목록과 NEW로 표시하며 해당 상세를 선택한 항목만 확인 처리합니다. 이름을 누르면 설명·제공된 날짜·수정된 날짜·버전·용량·권한과 설치·삭제 동작을 확인합니다. 확인되지 않은 날짜는 정보 없음으로 표시합니다. API 연결 메뉴 옆 **이름 변경** 버튼에서 API 연결·개인 공간·메이플 기능·개인 기능의 이름을 바꾸며 사이드바·기능 센터·홈 중요 기능에 함께 반영됩니다. 실제 기능 ID와 저장소는 바뀌지 않습니다.

0.26.0은 설치·업데이트·제거의 단위를 **기능팩 하나**로 고정합니다. 예를 들어 잠재능력/에디셔널 안의 시뮬레이터만 고쳐도 해당 팩의 새 버전 하나를 받습니다. 하위 도구는 우측 목록에서 선택하며 개별 설치나 별도 버전을 만들지 않습니다. 이 예시의 실제 계산 기능은 아직 준비 중입니다. 네 영역과 분류의 작성 원본은 `assets/feature-catalog/definition.json`이며 새 목록은 `catalog-index.json`과 영역별 hash 문서로 나눕니다. 기존 `packs-v1` 원본·구형 목록·SDK 1·개인 기록은 유지합니다. 자세한 형식은 [확장 계약](docs/FEATURE_CATALOG_V2.md)과 [운영 기준](docs/PACK_OPERATIONS.md)을 확인하세요.

### 개인 기능

- **생활 계산기**: 일반 계산기, 금액 한글 표기, 퍼센트, 날짜 계산, 단위 변환. 각각 오른쪽 도구 목록에서 선택합니다.
- **생각 보관함**: 여러 페이지에 글·제목·토글·체크리스트를 담고, 열과 카드가 있는 보드로 정리합니다. 명시적으로 저장하며 충돌이 나면 다시 읽기 또는 변경 비교 후 선택합니다.

현재 두 기능은 기능 센터에서 설치하는 별도 팩이며 본체 0.22.0 이상이 필요합니다. 기능 제거 시 실행 파일을 지워 용량을 확보하고 기록은 보관하거나 확인 후 함께 삭제합니다. 보관한 기록은 같은 기능을 재설치하면 이어서 읽습니다.

### 메이플 기능

과거 메이플 달력 배포 원본과 서명은 유지합니다. 메이플 달력1.2.0은 공식 이벤트·수동 일정을, 숙제 스케줄러1.0.0은 API 진행 상태·수동 숙제를 각각 담당합니다. 새 스케줄러 첫 설치 때 기존 달력의 지원되는 숙제 설정·수동 완료 기록만 복사하고 원본은 유지합니다. 이미 새 팩 기록이나 설치 이력이 있으면 덮어쓰거나 삭제된 기록을 되살리지 않습니다. 공식 이벤트 조회는 본인의 넥슨 API 키로 NEXON Open API를 호출하며 진행 중 최근 등록 최대 20개 범위를 따릅니다. 달력팩의 수동 기록과 본체 개인 일정은 서로 다른 저장소입니다. 준비 중인 강화·내실·보스 등의 이름은 아직 설치할 수 있는 기능이 아닙니다.

## 화면과 운영

왼쪽은 홈·개인 공간·메이플 기능·개인 기능, 가운데는 현재 화면, 오른쪽은 **기능 사이드바**입니다. 양쪽 펼친 너비는 240px이며 오른쪽은 접지 않습니다. 제목의 ! 안내로 도구 목록이 선택한 기능에 따라 바뀐다는 것을 확인합니다.

우측 기능 사이드바의 제목과 하단 **메켜놔 공식 채널**은 고정하고 가운데 영역만 별도로 스크롤합니다. 공식 사이트·유튜브는 주소 없이 디자인만 준비했습니다. 도구가 없는 화면은 208×360 세로 배너 자리를 표시하고 도구 목록이 있는 화면은 배너를 표시하지 않습니다. 실제 광고 SDK·광고 네트워크는 연결하지 않았습니다.

왼쪽 개인 공간·메이플 기능·개인 기능과 하위 분류는 부드럽게 접고 펼칩니다. 설정 → 메뉴 움직임에서 시스템 설정/부드럽게/끄기를 선택합니다. 신규/누락 설정의 기본값은 부드럽게이며 기존 명시적 선택은 유지합니다. 전체 사이드바 폭도 양방향650ms로 전환합니다. 시스템에서 효과가 꺼져 있으면 부드럽게를 선택해 이 앱의 메뉴에서만 켤 수 있습니다. 홈은 움직임이 꺼져 있어도 마우스에 배경·테두리로 반응합니다. 상위 세 구역의 접힘 상태는 저장합니다. 접힌 내용은 키보드와 보조기술 탐색에서도 제외하며 움직임 줄이기 설정을 따릅니다. 내부 분류 색은 줄이고 제목 왼쪽 강조선으로 구분합니다. 이벤트·계산 도구·기록 정리 분류만 아이콘을 표시하고 설치 기능은 이름으로 표시합니다. 홈 옆 또는 설정의 **사이드바 순서**에서 개인 공간과 네 기능 영역의 메뉴를 따로 정하고, 사이드바 구역 순서도 조정합니다. 기존 두 구역 설정은 보존해 읽습니다. 전체 사이드바를 접으면 이름 변경·사이드바 순서 버튼과 글자를 숨기고 분류 아이콘을 표시합니다. 홈과 펼친 상태의 사이드바 순서 버튼은 스크롤 밖 최상단에 고정하며 API 연결은 바로 아래에 둡니다. 구역 사이 구분선을 표시하고 기능 센터는 하단 설정 위에 고정합니다. 상단 현재 위치는 구역과 선택한 화면·도구 제목을 나눠 표시합니다.

본체는 화면 작업 영역 안에서 새 기본1600×900 또는 저장한 즐겨찾기 크기로 열고, 작은 화면은 왼쪽 메뉴를 아이콘으로 표시합니다. 가운데 본문만 스크롤하며 상단 표시줄과 사이드바는 유지합니다. 라이트·다크·시스템 선택은 화면과 왼쪽 사이드바를 함께 변경하고, 직접 농도를 조절하면 각각 10% 단위로 설정합니다. 시스템 모드는 OS 테마 변경을 따릅니다. 새 기본값은 각각 0%이며 이전 테마 선택은 유지합니다.

창의 ×는 시스템 트레이에 유지하며 트레이의 종료로 완전히 닫습니다. OS 자동 실행은 설정에서 ON/OFF합니다. 설치 기능은 별도 일반 창으로도 열 수 있으며 게임 클라이언트에 삽입하는 오버레이가 아닙니다.

업데이트를 시작·복귀·15분 주기로 자동 확인합니다. 새 본체는 노란색, 새 기능은 NEW, 설치 기능의 새 버전은 노란 상태로 구별합니다. 자동 발견만으로 다운로드나 설치를 시작하지 않습니다. 본체는 **업데이트하고 다시 시작**을 선택한 뒤 다운로드·설치 직전에 최신 정식 버전을 다시 확인해 중간 버전을 차례로 설치하지 않습니다. 이미 받은 버전보다 새 버전이 있으면 같은 요청 안에서 교체하고, 확인·검증 실패 시 설치를 중단합니다. 안내 창을 닫아도 승인한 업데이트는 계속됩니다.

본체 하단에는 `Data based on NEXON Open API`, ‘메이플스토리 관련 권리는 NEXON 등 각 권리자에게 있습니다.’, ‘메켜놔는 넥슨의 공식 서비스가 아닙니다.’를 표시합니다. Pretendard 1.3.9와 Tossface는 공식 배포 파일 원본·저작권·라이선스를 함께 보관합니다. 앱 정보의 **아이콘 출처 및 라이선스**에서 Tossface 고지와 라이선스 전문을 읽을 수 있습니다.

## 안전 안내

FAQ의 **안전한가요?**에서 게임 클라이언트 비접근, 공식 API 조회, 키 관리, 기능팩 검사와 정책 변경 시 기능 조정 원칙을 확인합니다. 메켜놔는 넥슨의 공식 제작·안전성 인증 프로그램이라고 주장하지 않습니다.

API 키·개인 기록·서명 개인 키는 공개 파일에 포함하지 않습니다. 본인의 API 키는 OS 암호화 저장소에 보관하며 연결 확인·이벤트 조회 때 공식 API 서버로 전송하고 기능팩에는 키 원문을 전달하지 않습니다. 게임 프로세스·메모리·패킷 접근, 게임 입력 자동화와 홈페이지 자동 수집 기능은 없습니다.

현행 기준은 [NEXON Open API 이용약관](https://openapi.nexon.com/ko/support/terms/)과 [메이플스토리 운영 안내](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/452)를 확인합니다. 정책과 API 범위에 따라 지원 기능이 바뀔 수 있습니다.

자동 검사는 업데이트 승인·최신 버전 확인·검증 실패·중복 요청·트레이 종료, 정적 화면 렌더링, 모듈 경계·IPC 발신자·기능팩 기록 보존을 다룹니다. TypeScript·Vite·Windows NSIS 빌드와 패키지의 소스·글꼴·라이선스·기존 팩 일치도 확인합니다. 버전별 실제 검사 수와 공개 게시·다운로드 검증 결과는 [배포 기록](docs/RELEASING.md)에 구분해 남깁니다.

이번 작업에서는 실제 앱 GUI를 실행하거나 직접 조작하지 않았습니다. 실제 설치 간 자동 업데이트·설치 후 재실행·Mac 실행은 별도 미검증입니다. 단위 검사와 설치 프로그램 컴파일을 실제 설치 검증으로 간주하지 않습니다.
