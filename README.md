# 메켜놔

메이플을 할 때와 일상에서 곁에 켜두는 개인 작업 공간입니다.

**[Windows 설치 파일 다운로드](https://github.com/bjpaku-pixel/mekyeonwa-releases/releases/latest)**

릴리스의 Assets에서 `windows-setup.exe`로 끝나는 파일을 받아 설치하세요.

현재 0.2.0은 홈·기능 센터·설정의 기본 화면과 개인 API 연결 설정을 제공하는 초기 개발 버전입니다. 보스 공략·계산기·메모 등 개별 기능과 Mac 설치본은 준비 중입니다.

설치형 앱 상단의 **업데이트**에서 새 버전을 확인하고 다운로드한 뒤 **다시 시작해 설치**로 적용할 수 있습니다. 이전 0.1.x 포터블 사용자는 새 설치본을 한 번 설치해야 합니다.

이 저장소에는 배포 안내와 설치 파일·업데이트 정보가 게시됩니다. API 키와 개인자료는 배포 파일에 포함하지 않습니다.
