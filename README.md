# 메켜놔

메이플과 일상의 기록을 모으고 필요한 기능을 골라 설치하는 개인 공간입니다.

**[Windows 본체 0.5.0 다운로드](https://github.com/bjpaku-pixel/mekyeonwa-releases/releases/latest)**

기존 설치형 앱은 상단 **본체 업데이트**를 사용하세요. 메이플 달력 **1.0.0**은 그대로 유지하며 다시 설치할 필요가 없습니다.

- 홈에서 오늘 체크·중요 일정·메모·링크·메이플 API 연결을 함께 확인합니다.
- 링크 수정 연필 왼쪽 별표로 즐겨찾기하고 분류를 직접 추가·이름 변경·삭제할 수 있습니다. 기본 링크는 제거하며 직접 추가한 링크는 보존합니다. 링크는 기본 웹브라우저에서 열립니다.
- 메모는 태그로 모아 보고 제목·내용·태그로 검색합니다. 색상은 장식으로 남습니다.
- 개인 일정은 날짜 클릭 추가·중요 표시·완료 체크와 2026~2027년 대한민국 공휴일 기본 표시·즐겨찾기·내 일정 추가를 제공합니다.
- 데일리 체크는 큰 글자·체크박스, 전체·미완료·완료 보기, 매일·매주 반복과 주간 기록을 제공합니다.
- 개인 공간·설치한 기능 옆 톱니바퀴에서 메뉴 순서와 두 구역의 위아래 위치를 바꿉니다.
- 기능 센터는 이름을 누르면 상세 설명과 설치 작업이 나타나는 작은 목록입니다. 우측 안내 영상은 아직 준비 중입니다.
- 새 본체 업데이트가 있으면 노란색으로 표시합니다.

이전 개인 기록은 새 형식으로 읽고 첫 저장 전에 원본을 한 번 보관합니다. 개인 기록은 이 기기에 저장합니다. GitHub 소스 백업과 클라우드 동기화는 별개이며 포맷 전에는 기록도 별도로 백업해야 합니다. API 키·개인 기록·서명 비밀키는 공개 파일에 포함하지 않습니다.

메이플 공식 이벤트와 주간 보스 체크는 **기능 센터 → 기능 업데이트 확인 → 메이플 달력 설치**로 사용할 수 있습니다. 공식 이벤트는 홈의 메이플 API 연결에 개인 Nexon API 키를 등록한 뒤 조회하며 API가 제공하는 진행 중 최근 등록 최대 20개 범위입니다. 개인 공간 일정과 메이플 달력의 기록은 자동 병합하지 않습니다.

본체와 기능팩은 별도로 업데이트하며 기존 SDK 1과 기록 저장 계약을 유지합니다. 기능팩 삭제·갱신으로 해당 기록을 초기화하지 않습니다.
