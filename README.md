## 강화 도구

**기능 센터 → 메이플 기능 → 강화 도구**에서 설치할 수 있습니다. 잠재능력/에디셔널 1.1.0에는 장비·등급별 확률표, 전후 비교 체험과 목표 옵션 기대값이 들어 있습니다. 다섯 팩에서 NEXON Open API로 캐릭터 장비를 조회할 수 있습니다. 체험과 기대값은 메켜놔에서 계산한 값입니다.

## 0.55.0 변경

메모를 넓은 문서형 편집기로 바꾸고, 달력의 완료 표시와 기념일 보기, 데일리 체크 목록과 시작 화면을 정리했습니다.

## 0.54.0 변경

메모의 서식 편집과 폴더·태그를 정리하고 일정과 데일리 체크의 표시 및 시간 입력을 개선했습니다.

## 0.53.0 변경

시작 화면에서 첫 실행, 개인 공간, 계정 연동 가이드를 둘러볼 수 있습니다. 로그인·로그인 없이 시작·컴퓨터를 켤 때 자동 실행을 오른쪽에 모았습니다.

## 0.52.0 변경

메모 제목과 본문 서식, 폴더·태그·링크 분류의 우클릭 메뉴를 추가했습니다. 일정·메모·링크에 변경 사항이 있으면 창 밖을 눌러도 편집창이 닫히지 않습니다. 달력은 우클릭으로 완료와 즐겨찾기를 조작하고 시간은 버튼이나 직접 입력으로 선택합니다.

## 0.51.0 변경

메모의 **폴더·태그 → ＋**에서 폴더를 만들 수 있습니다. 하나의 태그를 여러 폴더에 담고, 각 폴더에서 관련 메모를 한 번씩 봅니다. 폴더 배치는 이 PC에 저장합니다.

## 0.50.0 변경

개인 공간은 앱 시작, 창 복귀, 기록 변경 시 자동 동기화합니다. 데일리 체크에서 별표한 날짜 미정 할 일은 홈의 중요 일정 맨 앞에 표시합니다. 일정 표시 설정과 편집창의 즐겨찾기 위치를 정리했습니다.

## 0.48.0 변경

최신 시작 화면 시안을 적용하고 바깥 회색 여백을 제거했습니다. 작은 로고·자동 실행 설정과 큰 시작 버튼을 위로 모으고 광고 영역을 약2배 높이로 늘렸습니다.

일반 로그아웃·시작 화면 복귀는 현재 세션과 자동 로그인 토큰을 종료하고 개인 기록을 잠그며, 선택 저장한 아이디·OS 암호화 비밀번호는 유지합니다. 시작 화면의 로그인 정보 삭제를 선택하면 저장 정보까지 지웁니다. 공용 PC에서는 저장 옵션을 끄거나 이 삭제 기능을 사용하세요.

## 0.47.0 변경

로그인 계정의 개인 공간과 복구·보기 설정을 비밀번호 기반 암호화 저장소로 옮깁니다. 새 버전에서 해당 계정으로 다시 로그인해야 기존 기록의 변환이 적용됩니다. 시작 화면은 작은 자동 실행 토글로 바꾸고, 본체·기능팩의 GitHub 다운로드 장애 복구 경로를 추가했습니다. 기존 업데이트 창이 계속 실패한다면 위 설치 파일을 직접 한 번 실행하세요.

게스트 자료·기능팩 기록·다른 계정의 변환 전 과거 파일은 이번 암호화 대상에 포함되지 않습니다. 공용 PC에서는 로그인 정보를 저장하지 않고 사용 후 로그아웃하세요. 비밀번호 재설정 시 이전 로컬 암호화 기록은 별도 복구가 필요할 수 있습니다. 기존 기능팩 8개의 버전과 기록은 유지합니다.

## 이전 변경

내실 최적화는 장비·어빌리티·심볼·헥사 스탯/코어·V코어·아티팩트를 공식 API로 조회합니다. 기존 하이퍼·링크·유니온과 함께 우측 기능 목록에서 확인합니다. API 전투력은 적용 중인 상태의 원본으로 표시합니다. 메켜놔가 직접 작성한 상대 비교 모델은 해석 가능한 효과와 입력한 계산 조건만 사용하며, 미해석 효과가 있는 후보는 이유를 표시하고 자동 비교에서 제외합니다. 실제 최고 전투력이나 모든 조합의 최적값을 보장하지 않습니다.

보스 수익·익스트림 스우의 이전 출처가 불명확했던 구현은 독립 작성한 장부·타임라인과 기호로 교체했습니다. 사용자 기록·직접 입력한 가격·빌드는 유지합니다. 검증되지 않은 기본 가격표는 제거했으며 가격 미입력 기록은 합계에서 제외하고 별도로 표시합니다.

재배포 허락 자료가 없는 기본 네이버·메이플 사이트 아이콘은 기본 링크 기호로 바꿨습니다. 사용자가 등록한 아이콘과 링크 기록은 유지합니다.

API 키·원본 식별자를 기능팩에 전달하지 않습니다. 추가 조회 결과는 메모리에서만 사용하며 Firebase에 저장하지 않습니다. 게임 클라이언트·메모리·패킷·입력·홈페이지 수집에 접근하지 않습니다. 실제 사용자 API 키 조회·Windows 설치/재시작·Mac 실행은 이번 회귀 검사 범위에 포함하지 않았습니다.

Data based on NEXON Open API. 메이플스토리 관련 권리는 NEXON 등 각 권리자에게 있습니다. 메켜놔는 넥슨의 공식 서비스가 아닙니다.
