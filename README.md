# 메켜놔

메이플과 일상의 기록을 모으고 필요한 기능을 골라 설치하는 개인 공간입니다.

**[Windows 본체 0.9.0 다운로드](https://github.com/bjpaku-pixel/mekyeonwa-releases/releases/latest)**

기존 설치형 앱은 상단 **본체 업데이트 → 다운로드 → 다시 시작해 설치**를 사용하세요. 메이플 달력 **1.0.0**은 다시 설치할 필요가 없습니다.

0.9.0에서는 데일리 체크의 **오늘 → 전체**에서 모든 저장 내역을 검색하고 개별·현재 목록 전체 선택 삭제를 제공합니다. 반복 할 일의 모든 완료 기록 삭제도 확인합니다. 상단 톱니바퀴의 **우측 도구 패널**에서 기능팩이 제공하는 세부 도구를 모아 봅니다. 기존 달력은 목록을 등록하지 않으므로 안내만 표시합니다.

홈 상단 베타 배너와 데일리 아래 즐겨찾기 아이콘·이름 바로가기를 제공합니다. 링크는 사이트 파비콘 또는 직접 등록한 PNG·JPEG·WebP 이미지를 사용합니다. 날짜 클릭 빠른 추가 창을 개선하고, 설정 → **앱 시작 → 컴퓨터 시작 시 자동 실행**에서 설치형 Windows 앱의 자동 실행을 ON/OFF합니다. 기능 센터·이벤트 분류의 표시 숫자를 없앴으며 준비 중 이름은 **잠재능력/에디셔널**입니다. 광고·후원·Google 광고 연결과 해당 강화 도구의 실제 기능은 아직 없습니다.

- 업데이트를 받는 동안 작은 안내 카드와 실제 다운로드 진행률을 보여 줍니다. 설치는 진행 창에서 확인하며 정상 완료 후 앱을 다시 엽니다. 안내 카드는 접을 수 있습니다.
- 홈 우측 날짜를 누르면 개인 일정으로 이동합니다. 사이드바 설정·앱 정보 아래의 자주 묻는 질문에서 검색과 분류로 이용 방법을 찾을 수 있습니다.
- 기능 센터에서 실제 설치 파일·기능 기록의 용량을 확인합니다. **기능만 삭제**하면 기록을 보관하며, **기능과 기록 모두 삭제**는 별도 선택과 영구 삭제 확인 후 해당 기능의 기록도 지웁니다. 제거 후 남겨 둔 기록도 따로 정리할 수 있습니다.
- 기능 분류는 두 줄 다섯 칸입니다.

| 모든 분류 | 가이드 | 이벤트 | 보스 | 준비 중 |
| --- | --- | --- | --- | --- |
| 강화 도구 | 내실 분석기 | 템셋팅 | 준비 중 | 준비 중 |

요청한 22개 기능은 이름과 **준비 중** 표시만 제공합니다. 아직 설치할 수 없으며 실제 카탈로그·설치 수와 구분합니다. 현재 배포한 기능팩은 **메이플 달력 1.0.0** 하나이고 이벤트 분류에 표시합니다. 기존 기타 기능도 모든 분류와 사이드바에서 계속 접근할 수 있습니다.

전체/설치 범위와 분류·검색을 함께 선택합니다. 설치한 기능의 실제 새 버전이 발견되면 기능 업데이트 확인 버튼과 사이드바에 노란색으로 표시합니다. 시작·4시간 주기·포커스/온라인 복귀에 카탈로그를 자동 확인하며 자동 확인은 최소 15분 간격입니다. 다운로드·설치는 사용자가 선택합니다.

홈의 즐겨찾기 링크·상단 고정 메모·중요 일정과 할 일, 메모 태그·흰색, 개인 달력 빠른 추가·별표·2026~2027년 공휴일, 데일리 체크의 이전/다음 주 이동과 메뉴 위치 설정도 유지합니다. 공식 사이트와 설명 영상은 아직 준비 중입니다.

개인 기록은 이 기기에 저장합니다. GitHub 소스 백업과 클라우드 동기화는 별개이며 포맷 전 기록을 별도로 백업해야 합니다. 기록까지 삭제한 경우 앱에서 복원할 수 없습니다. API 키·개인 기록·서명 비밀키는 공개 파일에 포함하지 않습니다.

메이플 공식 이벤트와 주간 보스 체크는 **기능 센터 → 이벤트 → 메이플 달력 → 설치**로 사용할 수 있습니다. 공식 이벤트는 홈의 메이플 API 연결에 개인 Nexon API 키를 등록한 뒤 조회하며 API가 제공하는 진행 중 최근 등록 최대 20개 범위입니다. 개인 공간 일정과 메이플 달력의 기록은 자동 병합하지 않습니다.

본체와 기능팩은 별도로 업데이트하며 기존 SDK 1과 기록 저장 계약을 유지합니다. 팩 업데이트와 기록 보관을 선택한 제거는 기록을 초기화하지 않습니다.
