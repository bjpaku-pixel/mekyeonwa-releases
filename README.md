# 메켜놔

메이플과 일상의 기록을 모으고, 필요한 기능을 선택해 설치하는 데스크톱 개인 대시보드입니다.

**본체 0.17.0 · 메이플 달력 1.0.0 · 생활 계산기 1.0.1 · 생각 보관함 1.0.0**을 독립적으로 관리합니다.

[Windows 설치 파일](https://github.com/bjpaku-pixel/mekyeonwa-releases/releases/download/v0.17.0/mekyeonwa-0.17.0-windows-setup.exe) · [변경 내역](https://github.com/bjpaku-pixel/mekyeonwa-releases/releases/tag/v0.17.0)

기존 Windows 설치형 앱은 상단 **본체 업데이트**에서 새 버전을 받습니다. 다운로드·설치는 직접 선택합니다. 메이플 달력을 재설치할 필요는 없습니다. Mac 서명·설치·실행·업데이트는 아직 별도 검증이 필요합니다.

실행 화면은 기능 이름을 한 번만 표시하고, 도구 전환은 우측 기능 사이드바에서 합니다. 도구 항목은 이름만 표시합니다. 생활 계산기 1.0.1은 중앙 자체 선택 메뉴·중복 제목·소개를 없애고 계산 결과를 유지합니다.

## 개인 공간

- **홈 맞춤 설정**을 누르면 홈에서 바로 편집합니다. 카드 손잡이를 마우스로 끌거나 위·아래 버튼으로 순서를 바꾸고, 제목·표시·너비를 정한 뒤 강조된 하단 막대에서 저장합니다. 이동 안내는 ! 도움말로 확인합니다. 취소와 기본 구성 복원을 제공하며 숨긴 카드의 기록은 유지합니다.
- **데일리 체크와 일정은 같은 할 일 원본**을 사용합니다. 어느 화면에서 추가해도 날짜·중요 표시·시간·메모·반복·완료가 함께 반영됩니다. 일정은 달력으로 보고 데일리에서 자세히 체크합니다. 기존 버전에서 작성한 별도 일정도 보존·표시·편집합니다.
- 매일 반복은 날짜별로, 매주 목표는 선택한 초기화 요일부터 다음 주 전날까지 한 번 완료합니다. 미래 회차를 복사해 저장하지 않고 필요한 날짜에 계산합니다. 종료일 없는 반복과 완료 이력의 저장 한도는 별개입니다.
- 달력의 날짜 칸에서 Enter로 연속 등록하며 모든 항목을 표시합니다. 반복 기록 전체 삭제는 완료 내역도 지워진다는 확인을 받습니다.
- 메모는 내용과 태그를 구분해 입력하고 저장합니다. 상단 고정·모든 메모·태그 없음의 보기 순서를 설정합니다.
- 링크는 즐겨찾기·전체·미분류의 보기 순서를 정하고, 포인터로 순서·분류를 바꿉니다. 직접 아이콘과 네이버·메이플 파비콘을 지원하며 기본 웹브라우저로 엽니다.

개인 데이터 schema 5는 이전 1~4 기록을 읽습니다. 최초 새 형식 저장 전 이전 원본을 pre-v5 백업으로 한 번 보관합니다. 기록이 저장된 상태에서 구버전으로 되돌리면 새 형식을 읽지 못할 수 있습니다. 현재 기록·완료 내역에는 1MiB와 항목별 한도가 있으며 개인 기록 내보내기·가져오기와 기기 간 동기화는 추후 작업입니다.

홈의 즐겨찾는 기능은 **중요 메이플 기능**과 **중요 개인 기능**으로 나누며 이름 변경에 함께 반영됩니다. 기존 홈 배치·즐겨찾기·메뉴 순서는 유지합니다.

## 기능 센터

메이플 기능과 개인 기능을 각각 구별되는 영역 카드와 분류 박스 10개로 탐색합니다. 새로 추가된 기능은 이름 목록과 NEW로 표시하며 해당 상세를 선택한 항목만 확인 처리합니다. 이름을 누르면 설명·추가 날짜·수정 날짜·버전·용량·권한과 설치·삭제 동작을 확인합니다. 확인되지 않은 날짜는 정보 없음으로 표시합니다. API 연결 메뉴 옆 **이름 변경** 버튼에서 API 연결·개인 공간·메이플 기능·개인 기능의 이름을 바꾸며 사이드바·기능 센터·홈 중요 기능에 함께 반영됩니다. 실제 기능 ID와 저장소는 바뀌지 않습니다.

### 개인 기능

- **생활 계산기**: 일반 계산기, 금액 한글 표기, 퍼센트, 날짜 계산, 단위 변환. 각각 오른쪽 도구 목록에서 선택합니다.
- **생각 보관함**: 여러 페이지에 글·제목·토글·체크리스트를 담고, 열과 카드가 있는 보드로 정리합니다. 명시적으로 저장하며 충돌이 나면 다시 읽기 또는 변경 비교 후 선택합니다.

두 기능은 기능 센터에서 설치하는 별도 팩이며 본체 0.16.0 이상이 필요합니다. 기능 제거 시 실행 파일을 지워 용량을 확보하고 기록은 보관하거나 확인 후 함께 삭제합니다. 보관한 기록은 같은 기능을 재설치하면 이어서 읽습니다.

### 메이플 기능

메이플 달력 1.0.0의 원본·서명·SDK 1은 유지합니다. 공식 이벤트 조회는 본인의 넥슨 API 키로 NEXON Open API를 호출하며 진행 중 최근 등록 최대 20개 범위를 따릅니다. 달력팩의 수동 기록과 본체 개인 일정은 서로 다른 저장소입니다. 준비 중인 강화·내실·보스 등의 이름은 아직 설치할 수 있는 기능이 아닙니다.

## 화면과 운영

왼쪽은 홈·개인 공간·메이플 기능·개인 기능, 가운데는 현재 화면, 오른쪽은 **기능 사이드바**입니다. 양쪽 펼친 너비는 240px이며 오른쪽은 접지 않습니다. 제목의 ! 안내로 도구 목록이 선택한 기능에 따라 바뀐다는 것을 확인합니다.

오른쪽 상단과 하단의 **메켜놔 공식 채널**은 고정하고 가운데 영역만 별도로 스크롤합니다. 공식 사이트·디스코드는 주소 없이 디자인만 준비했습니다. 도구가 없는 화면은 208×360 세로 배너 자리를 표시하고 도구 목록이 있는 화면은 배너를 표시하지 않습니다. 실제 광고 SDK·광고 네트워크는 연결하지 않았습니다.

본체는 화면 작업 영역 안에서 기본 1720×1000으로 열고, 작은 화면은 왼쪽 메뉴를 아이콘으로 표시합니다. 가운데 본문만 스크롤하며 상단 표시줄과 사이드바는 유지합니다. 테마는 라이트·다크·시스템·다크 농도 10% 단위를 지원합니다.

창의 ×는 시스템 트레이에 유지하며 트레이의 종료로 완전히 닫습니다. OS 자동 실행은 설정에서 ON/OFF합니다. 설치 기능은 별도 일반 창으로도 열 수 있으며 게임 클라이언트에 삽입하는 오버레이가 아닙니다.

업데이트를 시작·복귀·15분 주기로 자동 확인합니다. 새 본체는 노란색, 새 기능은 NEW, 설치 기능의 새 버전은 노란 상태로 구별합니다. 다운로드나 설치는 자동으로 시작하지 않습니다.

## 안전 안내

FAQ의 **안전한가요?**에서 게임 클라이언트 비접근, 공식 API 조회, 키 관리, 기능팩 검사와 정책 변경 시 기능 조정 원칙을 확인합니다. 메켜놔는 넥슨의 공식 제작·안전성 인증 프로그램이라고 주장하지 않습니다.

API 키·개인 기록·서명 개인 키는 공개 파일에 포함하지 않습니다. 본인의 API 키는 OS 암호화 저장소에 보관하며 연결 확인·이벤트 조회 때 공식 API 서버로 전송하고 기능팩에는 키 원문을 전달하지 않습니다. 게임 프로세스·메모리·패킷 접근, 게임 입력 자동화와 홈페이지 자동 수집 기능은 없습니다.

현행 기준은 [NEXON Open API 이용약관](https://openapi.nexon.com/ko/support/terms/)과 [메이플스토리 운영 안내](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/452)를 확인합니다. 정책과 API 범위에 따라 지원 기능이 바뀔 수 있습니다.

자동 검사 710개 / 60개 파일, TypeScript·Vite·Windows 설치 빌드를 통과했습니다.

실제 앱 화면 직접 조작·설치 간 자동 업데이트·Mac 실행은 별도 미검증입니다.
