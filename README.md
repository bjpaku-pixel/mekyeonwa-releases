# 메켜놔

메이플과 일상의 기록을 모으고 필요한 기능팩을 골라 설치하는 개인 대시보드입니다. 현재 **본체 0.14.0 / 메이플 달력 기능팩 1.0.0**을 독립적으로 관리합니다.

[Windows 설치 파일](https://github.com/bjpaku-pixel/mekyeonwa-releases/releases/download/v0.14.0/mekyeonwa-0.14.0-windows-setup.exe) · [변경 내역](https://github.com/bjpaku-pixel/mekyeonwa-releases/releases/tag/v0.14.0)

기존 설치형 앱은 상단 **본체 업데이트**를 사용합니다. 달력팩을 재설치할 필요는 없습니다. Windows를 우선 배포하며 Mac 서명·설치·실행·업데이트 검증은 별도입니다.

## 화면과 사용 흐름

0.14.0은 창의 **× 닫기**를 누르면 앱을 종료하지 않고 시스템 트레이에 유지합니다. 트레이 아이콘 클릭이나 **메켜놔 열기**로 돌아오며 **종료** 메뉴를 누르면 완전히 종료합니다. 트레이를 만들 수 없는 환경에서는 일반 창 닫기로 동작합니다. 업데이트 설치와 운영체제 종료는 숨김 처리로 가로막지 않습니다.

본체 업데이트를 시작·복귀와 15분 주기로 자동 확인하며 실패 시 1·2·4·8·최대 15분 간격으로 재시도합니다. 이미 발견한 새 버전은 재확인·다운로드 오류 중에도 노란 표시를 유지합니다. 사이드바의 로고·공식 사이트 카드를 제거하고 부드러운 너비 전환·보라색 안내 툴팁을 제공합니다. 접힌 메뉴에서는 중요 기능 별표를 숨깁니다. 펼친 메뉴의 이벤트 등 분류 제목을 눌러 설치한 기능을 접고 펼칩니다. 접힌 메뉴에서는 분류 아이콘에 마우스를 올리거나 키보드로 열어 오른쪽 목록에서 기능을 선택합니다. 메뉴 순서 설정은 조절 아이콘, 앱 설정은 톱니바퀴로 구별합니다. 기능 센터의 이름 옆 상태는 최신(흰색)·업데이트(노란색)·준비중으로 구별하며 아직 설치하지 않은 기능은 설치 전으로 표시합니다.

0.11.1은 가운데 본문만 세로로 스크롤합니다. 본문 스크롤바는 우측 기능 목록의 왼쪽 경계에 위치하며 상단 표시줄·양쪽 사이드바·우측 안내와 커뮤니티 영역은 본문과 함께 움직이지 않습니다. 항목이 많은 팩은 도구 목록 안에서만 독립 스크롤합니다. 화면을 바꾸면 본문을 맨 위로 돌립니다.

왼쪽은 홈·개인 공간·기능 센터와 설치한 기능, 가운데는 현재 화면, 오른쪽은 **항상 표시되는 기능 목록**입니다. 등록 항목이 10개면 전체 10개를 표시합니다. 우측 너비를 조절할 수 있고 닫기·접기·겹쳐 표시 기능은 없습니다. 본체는 기본 1720×1000으로 열되 모니터 작업 영역을 넘지 않도록 맞춥니다. 작은 창에서는 왼쪽 메뉴를 아이콘으로 줄입니다. 톱니는 설정으로 바로 이동합니다.

홈 제목은 **개인 홈**이며 즐겨찾기 링크 바로가기·중요 일정·중요 기능·오늘 할 일·최대 4개 고정 메모를 표시합니다. **메이플 API 연결**은 홈 바로 아래의 별도 메뉴로 옮겼습니다. 중복되는 다가오는 일정·즐겨찾기 링크 카드는 제거했습니다. 중요 일정은 좌우로 넘기며 설치한 기능 옆 별표는 홈 중요 기능에 연결됩니다.

오른쪽 하단의 공식 사이트·디스코드는 **디자인만 준비한 상태**이며 주소가 없어 열리지 않습니다. 내장 타이머·스톱워치는 제거했고 설치한 기능 전체·항목의 별도 창은 유지합니다. 팩 창은 항상 위 표시·위치·크기 기억을 제공하고 본체 종료 시 함께 닫힙니다.

## 개인 공간

데일리의 날짜 있는 할 일도 달력에 표시합니다. **매일 반복**은 날짜마다 체크하고 **매주 목표**는 고른 초기화 요일부터 다음 주 전날까지 한 번 체크합니다. 예를 들어 목요일 초기화는 목~수 한 주를 공유하고 다음 목요일에 새 목표를 시작합니다. 모두 **계속 반복 · 종료일 없음**이며 미래 일정을 저장하지 않고 화면에 필요한 날짜만 계산합니다. 완료 기록은 누적되며 기존 1MB 저장 한도와 항목별 5,000개 완료 날짜 한도는 유지됩니다.

개인 기록은 schema 4로 올리고 이전 1~3 기록은 읽을 수 있습니다. 첫 저장 전에 이전 원본을 pre-v4 백업으로 한 번 보관합니다. 설치 기능팩과 개인 기록은 서로 다른 저장소를 사용합니다.

기본 메뉴는 데일리 체크 → 일정 → 메모 → 링크이며 저장한 사용자 순서는 유지합니다. 메뉴 순서 설정에서 기본 순서로 되돌릴 수 있습니다. 메모는 제목 입력 없이 내용부터 작성하며 **메모 저장을 눌러야 저장됩니다.** 안내를 표시합니다. 작은 카드에 내용·태그·날짜를 표시하며 기존 실제 제목과 본문은 보존합니다. 카드·내용·손잡이를 끌어 같은 핀 그룹 안에서 순서를 바꾸거나 왼쪽 태그·상단 고정·태그 없음으로 옮깁니다. **이동** 메뉴도 같은 동작을 제공하며 **태그 모두 해제**와 태그 없음으로의 드롭은 네/아니오로 한 번 더 확인합니다. 모아 보기 설정에서 상단 고정·모든 메모·태그 없음 순서를 바꾸면 다음에 메모를 열 때 첫 항목이 기본으로 표시됩니다. 작업 중 선택한 보기는 유지하며 이 순서는 개인 기록과 별도 환경설정 키에 저장합니다. 기존 저장 형식의 title은 비노출 요약으로 유지합니다.

링크 드래그는 같은 즐겨찾기 그룹의 카드 사이에서 **순서 변경만** 제공합니다. 왼쪽 분류로의 드롭은 받지 않으며 카드의 **이동** 메뉴로 분류·앞뒤 순서를 바꿉니다. 즐겨찾기는 분류를 유지합니다. 분류 추가·수정, 직접 이미지와 네이버·메이플 번들 파비콘을 유지하며 기본 웹브라우저로 엽니다.

드래그는 현재 화면에서 시작한 항목만 허용하고 저장 실패 시 원본과 기존 순서를 유지합니다. 메모·일정·링크의 **× 제거**는 현재 목록 선택·전체 선택·확인을 제공합니다. 일정 제거는 이달의 개인 일정만 대상으로 하며 기본 공휴일과 공휴일 즐겨찾기는 유지합니다.

개인 일정은 데일리 체크·홈과 같은 원본 및 완료 상태를 공유합니다. 일정의 날짜·내용·삭제 변경이 함께 반영되며 주간 통계·지난 미완료 일정에도 포함됩니다. 데일리 체크는 오늘/전체 내역, 날짜별 완료 기록, 주간 이동과 선택 삭제를 제공합니다. 개인 일정은 날짜 칸에서 제목·별표를 입력하고 Enter로 등록하면 같은 칸에서 다음 일정을 바로 입력합니다. 저장된 일정을 누르면 상세 편집을 엽니다. 공휴일 자료는 기존 2026~2027년 범위입니다.

## 기능팩과 연결

기능 센터의 전체 기능·설치한 기능 탭을 **메이플 기능·개인 기능**으로 바꿨습니다. 메이플 기능 → 이벤트 → 메이플 달력을 설치합니다. 개인 기능은 확장을 위한 빈 분류이며 실제 개인 기능팩을 배포한 상태가 아닙니다. 공식 이벤트 조회는 **메이플 API 연결** 메뉴에서 개인 넥슨 API 키를 등록한 뒤 사용하며 진행 중 최근 등록 최대 20개라는 API 범위를 따릅니다. 넥슨 로그인은 추후 작업입니다. 개인 공간 일정과 달력팩 기록을 자동 병합하지 않습니다.

준비 중 강화 도구·내실 분석기 등은 이름만 표시합니다. 기존 달력 1.0.0·SDK 1·서명 fixture·공개 카탈로그는 변경하지 않았습니다. 팩 창은 같은 저장소와 revision 충돌 보호를 사용하며 미저장 편집 자동 병합은 제공하지 않습니다.

본체와 기능팩의 새 버전을 시작·주기·복귀에 자동 확인하며 다운로드·설치는 사용자가 선택합니다. 신규 배포 기능은 NEW, 기존 설치 기능의 새 버전은 노란색으로 구별합니다. 기능팩 제거 시 기록을 보관하거나 별도 확인 후 함께 삭제합니다. Windows 설치형 앱의 OS 자동 실행은 설정에서 ON/OFF합니다.

개인 기록은 이 PC에 저장합니다. GitHub 소스 백업과 개인 기록 백업은 별개이며 내보내기·가져오기는 추후 작업입니다.

자동 검사 502개·TypeScript·Vite·Windows 설치 빌드를 통과했습니다. 실제 OS 트레이·드래그·설치 화면·설치 간 업데이트·Mac 실행은 별도 미검증이며 로컬 미리보기의 보안 차단을 우회하지 않았습니다.

API 키·개인 기록·서명 개인 키는 공개 파일에 포함하지 않습니다.
