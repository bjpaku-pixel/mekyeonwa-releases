# 메켜놔

메이플과 일상에서 사용하는 기능을 골라 설치하는 개인 작업 공간입니다.

**[Windows 본체 다운로드](https://github.com/bjpaku-pixel/mekyeonwa-releases/releases/latest)**

본체 **0.3.0**과 메이플 달력 **1.0.0**은 별도로 설치·업데이트합니다.

1. 기존 설치형 앱의 상단 **본체 업데이트**로 0.3.0을 설치하거나 최신 설치 파일을 받습니다.
2. **기능 센터 → 기능 업데이트 확인 → 메이플 달력 설치**를 누릅니다.
3. 왼쪽 메뉴의 메이플 달력을 엽니다.

달력은 공식 이벤트 목록, 개인 일정·약속·반복 일정과 완료 체크, 주간 보스 체크를 제공합니다. 공식 이벤트는 설정에 개인 Nexon API 키를 등록한 뒤 조회할 수 있습니다. API가 제공하는 진행 중 최근 등록 이벤트 최대 20개를 표시하며 전체 이벤트 이력을 보장하지 않습니다. 보스·약속 체크는 사용자가 직접 합니다.

새 달력 버전은 기능 센터에서 따로 업데이트합니다. 기능팩을 삭제하거나 업데이트해도 개인 일정과 체크 기록은 기기에 보관됩니다. API 키와 개인자료는 공개 배포 파일에 포함하지 않습니다.
