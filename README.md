# 메켜놔

메이플과 일상의 기록을 모으고 필요한 기능을 골라 설치하는 개인 공간입니다.

**[Windows 본체 0.7.0 다운로드](https://github.com/bjpaku-pixel/mekyeonwa-releases/releases/latest)**

기존 설치형 앱은 상단 **본체 업데이트 → 다운로드 → 다시 시작해 설치**를 사용하세요. 메이플 달력 **1.0.0**은 다시 설치할 필요가 없습니다.

- 사이드바의 **기능 센터**를 테두리로 구분하고, 설치한 기능은 **가이드·이벤트·보스·편리 기능**별 색상과 아이콘으로 모아 표시합니다.
- 기능 센터 상단에서 전체/설치 범위와 네 분류·검색을 함께 선택할 수 있습니다. 이름을 누르면 상세 설명을 확인하며 우측 안내 영상은 준비 중입니다.
- 설치한 기능의 실제 새 버전이 발견되면 **기능 업데이트 확인** 버튼과 사이드바에 노란색으로 표시합니다. 시작·4시간 주기·앱 포커스·온라인 복귀에 목록을 자동 확인하며 자동 확인 간격은 최소 15분입니다. 다운로드·설치는 사용자가 선택합니다.
- 현재 배포한 기능팩은 **메이플 달력 1.0.0** 하나이며 이벤트 분류에 표시합니다. 다른 분류에는 앞으로 기능을 추가합니다.
- 홈은 큰 글자·진행 표시·요약 카드와 즐겨찾기 링크·상단 고정 메모를 제공합니다. 링크는 즐겨찾기, 메모는 상단 고정이 첫 기본 보기입니다.
- 흰색 메모·태그·검색·고정, 개인 달력의 빠른 일정 추가·별표·2026~2027년 공휴일, 데일리 체크의 이전/다음 주 이동과 메뉴 위치 설정을 제공합니다.
- 본체 업데이트도 시작·4시간 주기·앱/절전/온라인 복귀에 자동 확인해 노란색으로 알립니다. 상단 우측은 설정 톱니바퀴, 좌측 상단은 공식 사이트 준비 안내입니다. 공식 사이트 URL은 아직 없습니다.

개인 기록은 이 기기에 저장합니다. 이전 기록 형식은 첫 저장 전에 원본을 한 번 보관합니다. GitHub 소스 백업과 클라우드 동기화는 별개이며 포맷 전에는 기록도 별도로 백업해야 합니다. API 키·개인 기록·서명 비밀키는 공개 파일에 포함하지 않습니다.

메이플 공식 이벤트와 주간 보스 체크는 **기능 센터 → 이벤트 → 메이플 달력 → 설치**로 사용할 수 있습니다. 공식 이벤트는 홈의 메이플 API 연결에 개인 Nexon API 키를 등록한 뒤 조회하며 API가 제공하는 진행 중 최근 등록 최대 20개 범위입니다. 개인 공간 일정과 메이플 달력의 기록은 자동 병합하지 않습니다.

본체와 기능팩은 별도로 업데이트하며 기존 SDK 1과 기록 저장 계약을 유지합니다. 기능팩 삭제·갱신으로 해당 기록을 초기화하지 않습니다.
