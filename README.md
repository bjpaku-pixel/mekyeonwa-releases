# 메켜놔

메이플과 일상의 기록을 모으고 필요한 기능을 골라 설치하는 개인 공간입니다.

**[Windows 본체 0.6.0 다운로드](https://github.com/bjpaku-pixel/mekyeonwa-releases/releases/latest)**

기존 설치형 앱은 상단 **본체 업데이트 → 다운로드 → 다시 시작해 설치**를 사용하세요. 메이플 달력 **1.0.0**은 다시 설치할 필요가 없습니다.

- 홈을 큰 글자·진행 표시·요약 카드로 정리하고 **즐겨찾기 링크·상단 고정 메모만** 보여 줍니다.
- 링크의 첫 메뉴·기본 보기는 즐겨찾기, 메모는 상단 고정입니다. 해당 보기에서 새 항목은 즐겨찾기·고정 상태로 추가합니다. 기존 일반 항목은 전체 보기에서 그대로 확인할 수 있습니다.
- 흰색 메모를 추가했습니다. 다크 테마에서는 중립 배경으로 표시하며 태그·검색·색상·고정을 지원합니다.
- 개인 달력 날짜를 누르면 작은 창에서 제목·선택 시간·즐겨찾기를 바로 추가하고, 같은 날 기존 일정·공휴일에도 별표를 붙입니다. 자세한 편집으로 입력을 이어 갈 수 있습니다.
- 데일리 체크는 이전 주·다음 주·이번 주 복귀와 기간 표시를 제공합니다.
- 본체 업데이트는 시작·4시간 주기·앱/절전/온라인 복귀에 자동 확인하며 새 버전을 발견하면 노란색으로 표시합니다. 자동 확인은 최소 15분 간격이고 다운로드·설치는 사용자가 선택합니다.
- 상단 우측은 설정 톱니바퀴입니다. 좌측 상단은 공식 사이트 준비 안내이며 실제 사이트 URL은 아직 없습니다.
- 메뉴 위치·링크 분류 관리·태그·2026~2027년 공휴일과 개인 메모·일정·체크 기록을 제공합니다. 기능 센터의 안내 영상은 준비 중입니다.

개인 기록은 이 기기에 저장합니다. 이전 기록 형식은 첫 저장 전에 원본을 한 번 보관합니다. GitHub 소스 백업과 클라우드 동기화는 별개이며 포맷 전에는 기록도 별도로 백업해야 합니다. API 키·개인 기록·서명 비밀키는 공개 파일에 포함하지 않습니다.

메이플 공식 이벤트와 주간 보스 체크는 **기능 센터 → 기능 업데이트 확인 → 메이플 달력 설치**로 사용할 수 있습니다. 공식 이벤트는 홈의 메이플 API 연결에 개인 Nexon API 키를 등록한 뒤 조회하며 API가 제공하는 진행 중 최근 등록 최대 20개 범위입니다. 개인 공간 일정과 메이플 달력의 기록은 자동 병합하지 않습니다.

본체와 기능팩은 별도로 업데이트하며 기존 SDK 1과 기록 저장 계약을 유지합니다. 기능팩 삭제·갱신으로 해당 기록을 초기화하지 않습니다.
